## P2 与跨模块问题

### 存储

- 独立查询全部已登记路径，避免 LIMIT 外的文件被重复当作孤儿；排除预览临时文件，支持 AVIF，并通过文件身份处理大小写差异。
- 归属匹配改用目录前缀索引，避免实体数乘以文件数的扫描。媒体库缓存构建合并并发请求，命中缓存无需等待构建锁；TTL 为 5 分钟。
- 媒体库显式返回是否截断，恰好达到上限时不误报警。任务文件查询读取上限加一条，返回截断标记和稳定的空数组。
- 配置更新串行合并，缓存具有 1 秒 TTL；部分字段提交按字段是否存在合并。数据库文件名进行 DSN 编码。
- 计划领取按同一时间点比较，避免文本时间格式差异；单行坏 JSON 不阻断其他计划，错误记录日志。
- 下载 URL、媒体键和预览 URL 的历史迁移按 ID 每批最多读取 1000 行，保留事务内去重和索引重建。目录前缀改写使用原子 SQL 更新。
- 数据目录增加 OS 文件锁，防止两个服务进程共同领取或重排同一库的任务。

### 任务、客户端与解析

- 调度异常有恢复与堆栈日志；维护工作移出调度协程并纳入关闭等待。任务结束主动唤醒调度。
- 关闭流程先停止服务和工作线程，再关闭数据库；无法排空时非零退出，避免关闭数据库后继续写入。
- 状态广播使用数据库实际更新结果；目录改名后数据库更新失败会回滚文件系统改名；链接创建遇到竞争后重新核验目标，名称过滤控制字符。
- 失败队列、媒体计数和增量游标的持久化错误向上传播；缺失媒体 URL 计入失败，不静默推进游标。
- API 错误不再因 `data` 非空而吞掉限流或凭据错误；异常 timeline 与解析失败报错，只有 cursor 的空页继续翻页。
- 解析长文、不可用推文及官方 `/i/web/status` 分享链接；无时间时从 Snowflake 推导，非法时间报错。
- Cookie 检测复用任务客户端池；重定向限制次数、同源与 HTTPS，32 MiB 响应超限明确报错，非法请求不预扣配额，布尔回退跳过 null。

### HTTP、下载与静态资源

- 下载仅接受 HTTP 200，限制重定向次数并拒绝 HTTPS 降级；海报文件也经过符号链接与路径沙箱检查。
- JSON 响应在 identity/压缩分支均缓冲并处理 panic，避免发送半份 JSON；请求体超限可关闭连接，HEAD 与 Vary 行为对齐。
- 媒体库支持服务端分页、用户/类型/搜索筛选，默认每页 60、最多 200；保留旧数组接口，默认最多 100 条。
- 下载目录环境变量实际生效，启动和保存均拒绝全盘根与家目录本身；创建目录使用 0700，上级目录导航遵守后端允许范围。
- 静态资源缓存按文件大小和修改时间失效并限制数量；仅允许 GET/HEAD，正确处理 `/api`、带点路由、弱 ETag 与损坏压缩 sidecar。

### 前端与构建

- 查询错误与空结果分开展示；API 支持超时、取消及非 JSON 错误文案；未知任务状态有降级展示。
- SSE 重连补拉包含任务文件；任务终态失效失败队列。后端聚合错误的次数、账号数和异常种类分别解析。
- 主题实例和标签页同步；保存中的新编辑不会被旧响应覆盖，GET 与 PUT 不同的配置在等待超时后同步，重新加载可丢弃草稿。
- 目录树同路径刷新有效，加载失败不保留旧树；Cookie 粘贴规范化，父级更新移出 state updater。
- 整数输入、无标题弹层关闭、无 scheme 链接、筛选路由状态等行为已核验；视频海报来源更新会重试，连续复制反馈不被旧计时器提前清除。
- 搜索下拉的 combobox 语义由聚焦输入框持有；错误 Toast 使用 alert，键盘焦点与悬停均暂停自动关闭。
- Docker 与 release 使用同一静态同步脚本；增加 HEALTHCHECK、停止信号、构建忽略项；CI 校验内嵌产物、格式、竞态与 Docker 构建；发布门禁在缺失/失败 CI 时拒绝放行。
- Actions 引用固定 SHA，启动输出版本信息；开发依赖兼容补丁更新后，`npm audit` 与生产依赖审计均为 0 项。

## 报告中需要区分的项目

| 项目 | 判定与保留边界 |
| --- | --- |
| 修改下载目录后直接重写所有历史路径 | 原建议不完整：未搬文件却改路径会产生另一种丢失。采用可信历史根方案，切换配置不自动搬迁文件。 |
| 初始下载 URL 必须全部限定 twimg | 通用下载器本身接受 URL；HTTP 任务与推文解析入口已有主机约束。不能把通用库能力直接视为已可利用漏洞。 |
| 代理后仍能本地固定目标 DNS/IP | HTTP 代理可能自行解析目标，属于可信代理边界；本地拨号校验不能证明代理内部目的地址。未改变代理协议或声称完全消除此边界。 |
| `.bin` 必须作为画廊媒体开放 | `.bin` 没有确定媒体类型，不开放任意二进制文件；已补齐可识别的 AVIF。 |
| 1 小时临时文件清理误删超长正常下载 | 正常下载超时为 10 分钟，清理阈值更长，当前约束下未确认该出错场景。 |
| `MaxConcurrency`、预留锁、死表/接口、重复 helper | 串行执行是现有产品约定；清理兼容字段或组织代码属于技术债，不据此开放并发或扩大重构。 |
| 硬编码 X queryId、WAF 403、404/410 与签名 URL 刷新 | 依赖外部接口与错误策略，未使用真实 Cookie 做线上验证。不能依据推测自动更新 queryId、把所有 403 当挑战，或把所有 404 当瞬时错误。 |
| 404/410 不可用媒体保留 180 天 | 保留现有策略及老化恢复；缩短时间或增加重新解析流程属于产品行为调整。 |
| 无内置鉴权 | 报告明确列为产品决策项。保留默认回环监听与既有反代鉴权边界，没有擅自加入登录系统。 |
| 覆盖率目标、访问日志/请求 ID、全局超时、lint 工具选型 | 属于改进建议；已补直接相关回归测试与错误日志，不以达到某个覆盖率或新增工具作为修复完成标准。SSE/下载也不适合统一短超时。 |
